# Electronic Pass System

## О проекте

Проект посвящён анализу и проектированию веб-приложения для автоматизации процесса оформления выхода учащихся за территорию образовательного учреждения.

## Цель проекта

Разработать аналитическую документацию, описывающую требования, бизнес-процессы, пользовательские сценарии, структуру данных и взаимодействие компонентов веб-приложения.

## Основные задачи

- Анализ предметной области и существующего бизнес-процесса.
- Выявление проблем и определение требований к веб-приложению.
- Определение заинтересованных лиц и пользователей системы.
- Разработка пользовательских сценариев (Use Case).
- Моделирование бизнес-процессов и взаимодействия компонентов.
- Проектирование структуры данных.
- Подготовка технической документации.

## Инструменты и технологии

- BPMN
- UML
- SQL
- REST API
- Swagger / OpenAPI
- GitHub

## Статус проекта

В разработке. Аналитическая документация дополняется по мере выполнения практических заданий и изучения новых инструментов системного анализа.
