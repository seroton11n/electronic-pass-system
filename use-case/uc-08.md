# UC-08. Просмотр заявок

## 1. Контекст использования

Заместитель директора по воспитательной работе использует раздел «Заявки», чтобы просматривать заявки на выход учащихся за выбранную дату, отслеживать их текущие статусы в разрезе классов и знакомиться с подробной информацией по выбранной заявке.

## 2. Область действия

Веб-приложение «Электронный пропуск».

## 3. Основное действующее лицо

Заместитель директора по воспитательной работе.

## 4. Участники

Отсутствуют.

## 5. Предусловия

1. Заместитель директора по воспитательной работе авторизован в системе.

## 6. Гарантии успеха

1. Заместителю директора по воспитательной работе доступен список заявок на выход учащихся за выбранную дату с группировкой по классам и указанием их текущих статусов.
2. Заместитель директора по воспитательной работе может ознакомиться с подробной информацией по выбранной заявке.

## 7. Триггер

Заместителю директора по воспитательной работе необходимо просмотреть поступившие заявки на выход учащихся, ознакомиться с их текущими статусами и подробной информацией.

## 8. Основной сценарий

1. Заместитель директора по воспитательной работе открывает раздел «Заявки».
2. Система отображает страницу «Заявки» с элементом выбора даты.
3. Заместитель директора по воспитательной работе выбирает дату, за которую необходимо просмотреть заявки.
4. Система отображает список классов. Для каждого класса указываются:
   - наименование класса;
   - фамилия и инициалы воспитателя;
   - количество заявок, ожидающих рассмотрения;
   - количество заявок, по которым заместитель директора по воспитательной работе уже принял решение.
5. Заместитель директора по воспитательной работе выбирает нужный класс.
6. Система отображает список заявок учащихся выбранного класса за указанную дату. Для каждой заявки отображаются:
   - фамилия и имя учащегося;
   - причина выхода;
   - сведения о сопровождающем лице.
7. Заместитель директора по воспитательной работе выбирает заявку, подробную информацию о которой хочет просмотреть.
8. Система открывает подробную карточку выбранной заявки и отображает:
   - сведения об учащемся: фамилию, имя и класс;
   - дату и время выхода;
   - дату и время возвращения;
   - причину выхода;
   - сведения о сопровождающем лице;
   - результат медицинской проверки и комментарий медицинского работника, если проверка уже проведена;
   - текущий статус заявки.
9. Заместитель директора по воспитательной работе возвращается к списку заявок.

## 9. Альтернативные сценарии (расширения)

### 4а. На выбранную дату отсутствуют заявки.

1. Система отображает сообщение «Нет заявок на выбранную дату».
2. Выполнение сценария завершается.

### 6а. В выбранном классе отсутствуют заявки на указанную дату.

1. Система отображает сообщение об отсутствии заявок в выбранном классе.
2. Заместитель директора по воспитательной работе возвращается к списку классов.
3. Выполнение сценария продолжается с шага 5 основного сценария.

### 2а, 4б, 8а. Возникают технические неполадки при загрузке данных.

1. Система обнаруживает техническую ошибку при выполнении операции.
2. Система сообщает заместителю директора по воспитательной работе о возникновении технических неполадок.
3. Система предлагает повторить попытку позднее.
4. Выполнение сценария завершается.
