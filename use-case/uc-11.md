# UC-11. Просмотр истории выходов

## 1. Контекст использования

Заместитель директора по воспитательной работе использует раздел «История выходов», чтобы просматривать сведения о ранее состоявшихся выходах и возвращениях учащихся, отслеживать историю их отсутствия и при необходимости формировать отчётность.

## 2. Область действия

Веб-приложение «Электронный пропуск».

## 3. Основное действующее лицо

Заместитель директора по воспитательной работе.

## 4. Участники

Отсутствуют.

## 5. Предусловия

1. Заместитель директора по воспитательной работе авторизован в системе.

## 6. Гарантии успеха

1. Заместителю директора по воспитательной работе доступна история завершённых выходов учащихся за выбранный период.
2. Пользователь может просмотреть подробную информацию о каждом выходе.
3. Пользователь может экспортировать полную информацию об истории выходов в формате PDF или Excel.

## 7. Триггер

Заместителю директора по воспитательной работе необходимо просмотреть историю выходов учащихся или экспортировать сведения о завершённых выходах для дальнейшего использования.

## 8. Основной сценарий

1. Заместитель директора по воспитательной работе открывает раздел «История выходов».
2. Система отображает элементы фильтрации истории выходов, включая выбор периода и класса.
3. Заместитель директора по воспитательной работе указывает интересующий период времени и при необходимости выбирает класс.
4. Система отображает таблицу с историей завершённых выходов учащихся за выбранный период. В таблице представлены следующие сведения:
   - учащийся (фамилия и имя);
   - класс;
   - дата выхода;
   - фактическое время выхода;
   - дата возвращения;
   - фактическое время возвращения;
   - продолжительность отсутствия.
5. Заместитель директора по воспитательной работе выбирает запись, подробную информацию о которой необходимо просмотреть.
6. Система открывает карточку выбранной записи и отображает подробную информацию:
   - причину выхода;
   - сведения о сопровождающем лице;
   - запланированные дату и время выхода и возвращения;
   - фактические дату и время выхода и возвращения;
   - cотрудник охраны, зафиксировавший выход и возвращение.
7. Заместитель директора по воспитательной работе изучает информацию о выбранной записи.

## 9. Альтернативный сценарий (расширение)

**4а. За выбранный период отсутствуют завершённые выходы.**

1. Система сообщает об отсутствии записей за выбранный период.
2. Вариант использования завершается.

**4б. Заместитель директора по воспитательной работе хочет экспортировать историю выходов.**

1. Заместитель директора нажимает кнопку «Экспорт PDF» или «Экспорт Excel».
2. Система формирует файл в выбранном формате, содержащий полную информацию о завершённых выходах за выбранный период. В файл включаются сведения из таблицы и подробная информация о каждой записи.
3. Система предоставляет сформированный файл для сохранения.

**4б.1. При формировании файла экспорта возникает техническая ошибка.**

1. Система сообщает о невозможности сформировать файл.
2. Заместитель директора по воспитательной работе может повторить попытку экспорта.

**2а. При загрузке истории выходов возникает техническая ошибка.**

1. Система сообщает об ошибке загрузки данных.
2. Заместитель директора по воспитательной работе может повторить попытку загрузки истории выходов.
