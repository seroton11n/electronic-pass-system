# UC-14. Просмотр текущих выходов учащихся

## 1. Контекст использования

Воспитатель имеет возможность просматривать сведения об учащихся своего класса, которые в данный момент находятся за территорией гимназии-интерната, чтобы отслеживать текущие выходы и контролировать своевременное возвращение учащихся.

## 2. Область действия

Веб-приложение «Электронный пропуск».

## 3. Основное действующее лицо

Воспитатель.

## 4. Участники

Отсутствуют.

## 5. Предусловия

1. Воспитатель авторизован в системе.
2. За воспитателем закреплён определённый класс.

## 6. Гарантии успеха

1. Воспитателю доступен список учащихся его класса, которые в текущий момент находятся за территорией гимназии-интерната.
2. Воспитатель может просмотреть подробную информацию о выбранном учащемся.
3. Воспитатель может экспортировать доступные данные в формате PDF или Excel.

## 7. Триггер

Воспитателю необходимо получить актуальную информацию об учащихся своего класса, которые в данный момент находятся за территорией гимназии-интерната.

## 8. Основной сценарий

1. Воспитатель открывает раздел «Текущие выходы учащихся».
2. Система отображает список учащихся закреплённого за воспитателем класса, которые в данный момент находятся за территорией гимназии-интерната. Для каждого учащегося указываются:
   - фамилия и имя;
   - фактическое время выхода;
   - планируемое время возвращения.
3. Воспитатель выбирает учащегося, подробную информацию о котором хочет просмотреть.
4. Система раскрывает карточку выбранного учащегося и отображает:
   - фамилию и имя учащегося;
   - дату выхода;
   - причину выхода;
   - сведения о сопровождающем лице;
   - фактическое время выхода;
   - планируемое время возвращения.
5. Воспитатель изучает информацию о выбранном учащемся.

## 9. Расширения

**2а. В системе отсутствуют текущие выходы учащихся закреплённого класса.**

1. Система сообщает об отсутствии учащихся, находящихся за территорией гимназии-интерната.
2. Выполнение сценария завершается.

**2б. При загрузке данных или формировании файла экспорта возникает техническая ошибка.**

1. Система обнаруживает техническую ошибку при выполнении операции.
2. Система отображает сообщение о возникшей технической ошибке.
3. Выполнение сценария завершается.

**2в. Воспитатель принимает решение экспортировать данные.**

1. Воспитатель нажимает кнопку «Экспортировать», расположенную в верхней части страницы.
2. Система предлагает выбрать формат файла: PDF или Excel.
3. Воспитатель выбирает необходимый формат.
4. Система формирует файл с данными о текущих выходах учащихся его класса в выбранном формате.
5. Система предоставляет возможность сохранить сформированный файл на устройство пользователя.
6. Сценарий продолжается с шага 3 основного сценария.
