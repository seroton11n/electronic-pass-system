# UC-8. Просмотр заявок

## 1. Контекст использования

Заместитель директора по воспитательной работе использует раздел «Заявки», чтобы просматривать поступившие заявки на выход учащихся всех классов, отслеживать их текущие статусы и знакомиться с подробной информацией по выбранной заявке.

## 2. Область действия

Веб-приложение «Электронный пропуск».

## 3. Основное действующее лицо

Заместитель директора по воспитательной работе.

## 4. Участники

Отсутствуют.

## 5. Предусловия

1. Заместитель директора по воспитательной работе авторизован в системе.

## 6. Гарантии успеха

1. Заместителю директора по воспитательной работе доступен список заявок на выход учащихся всех классов с указанием их текущих статусов.
2. Заместитель директора по воспитательной работе может ознакомиться с подробной информацией по выбранной заявке.

## 7. Триггер

Заместителю директора по воспитательной работе необходимо просмотреть поступившие заявки на выход учащихся, ознакомиться с их текущими статусами и подробной информацией.

## 8. Основной сценарий

1. Заместитель директора по воспитательной работе открывает раздел «Заявки».
2. Система отображает страницу «Заявки».
3. Система отображает список текущих заявок на выход учащихся всех классов. Для каждой заявки отображаются:
   - фамилия и имя учащегося;
   - класс учащегося;
   - дата и время выхода;
   - текущий статус заявки.
4. Заместитель директора по воспитательной работе выбирает заявку, подробную информацию о которой хочет просмотреть.
5. Система открывает подробную карточку выбранной заявки и отображает:
   - сведения об учащемся: фамилию, имя и класс;
   - дату и время выхода;
   - дату и время возвращения;
   - причину выхода;
   - сведения о сопровождающем;
   - результат медицинской проверки и комментарий медицинского работника, если проверка уже проведена;
   - текущий статус заявки.
6. Заместитель директора по воспитательной работе возвращается к списку заявок.

## 9. Альтернативные сценарии (расширения)
### 3а. В системе отсутствуют текущие заявки.

1. Система отображает пустой список заявок.
2. Система сообщает заместителю директора по воспитательной работе об отсутствии текущих заявок.
3. Выполнение сценария завершается.

### 2а, 3б, 5а. Возникают технические неполадки при загрузке данных.

1. Система обнаруживает техническую ошибку при выполнении операции.
2. Система сообщает заместителю директора по воспитательной работе о возникновении технических неполадок.
3. Система предлагает повторить попытку позднее.
4. Выполнение сценария завершается.
