# UC-3. Просмотр активных заявок

## 1. Контекст использования

Родитель (законный представитель) использует функцию просмотра активных заявок, чтобы ознакомиться со списком поданных заявок, просмотреть подробную информацию по каждой из них и отслеживать изменение их статусов.

## 2. Область действия

Веб-приложение «Электронный пропуск».

## 3. Основное действующее лицо

Родитель (законный представитель).

## 4. Участники

Отсутствуют.

## 5. Предусловия

1. Родитель (законный представитель) авторизован в системе.

## 6. Гарантии успеха

1. Родителю доступен список созданных им активных заявок.
2. Родитель может ознакомиться с подробной информацией по выбранной заявке.
3. Родитель может увидеть текущий статус каждой заявки.

## 7. Триггер

Родителю (законному представителю) необходимо ознакомиться с информацией о поданных активных заявках, в том числе проверить их текущие статусы.

## 8. Основной сценарий

1. Родитель открывает раздел «Активные заявки».
2. Система отображает страницу «Активные заявки».
3. Система отображает список заявок, созданных данным родителем и находящихся в обработке.
4. Система отображает для каждой заявки дату и время выхода учащегося.
5. Система отображает фамилию и имя учащегося, а также его класс.
6. Система отображает сведения о сопровождающем и текущий статус заявки в виде соответствующей плашки.
7. Родитель выбирает заявку, подробную информацию о которой хочет просмотреть.
8. Система открывает страницу с подробной информацией по выбранной заявке.
9. Родитель возвращается к списку активных заявок.

## 9. Альтернативные сценарии (расширения)

### 3а. В системе отсутствуют активные заявки, созданные данным родителем.

1. Система отображает страницу «Активные заявки».
2. Система сообщает об отсутствии активных заявок.
3. Выполнение сценария завершается.

### 8а. Возникают технические неполадки при загрузке подробной информации о заявке.

1. Система сообщает родителю о том, что в приложении возникли технические неполадки.
2. Система предлагает повторить попытку позднее.
3. Выполнение сценария завершается.
