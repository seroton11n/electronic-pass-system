# UC-07. Проверка медицинских противопоказаний

## 1. Контекст использования

Медицинский работник рассматривает заявки, ожидающие медицинской проверки, определяет, имеются ли у учащегося медицинские противопоказания для выхода за территорию гимназии-интерната, и выносит соответствующее медицинское заключение, на основании которого заявка передаётся на дальнейшее согласование или отклоняется.

## 2. Область действия

Веб-приложение «Электронный пропуск».

## 3. Основное действующее лицо

Медицинский работник.

## 4. Участники

Отсутствуют.

## 5. Предусловия

1. Медицинский работник авторизован в системе.
2. В системе имеется заявка, ожидающая медицинской проверки.

## 6. Гарантии успеха

1. Медицинское заключение по заявке вынесено и сохранено в системе.
2. При положительном медицинском заключении заявке присвоен статус «Ожидает рассмотрения заместителем директора по воспитательной работе», после чего она передана на дальнейшее согласование.
3. При отрицательном медицинском заключении заявке присвоен статус «Отклонено», а родителю направлено уведомление с указанием причины отказа.
## 7. Триггер

Медицинскому работнику необходимо провести медицинскую проверку поступившей заявки и вынести заключение о возможности выхода учащегося за территорию гимназии-интерната.

## 8. Основной сценарий

1. Медицинский работник открывает раздел «Заявки».
2. Система отображает страницу «Заявки» со списком заявок, ожидающих медицинской проверки.
3. Медицинский работник выбирает заявку из списка.
4. Система открывает подробную карточку выбранной заявки и отображает информацию об учащемся, периоде отсутствия, причине выхода и сопровождающем.
5. Медицинский работник изучает информацию в карточке заявки и проверяет наличие медицинских противопоказаний для выхода учащегося за территорию гимназии-интерната.
6. Медицинский работник выбирает решение «Разрешено».
7. Система сохраняет положительное медицинское заключение по заявке.
8. Система присваивает заявке статус «Ожидает рассмотрения заместителем директора по воспитательной работе» и передаёт её на дальнейшее согласование.
9. Медицинский работник нажимает кнопку возврата к списку заявок.
10. Система отображает страницу «Заявки».

## 9. Альтернативные сценарии (расширения)

### 6а. Медицинский работник выносит отрицательное медицинское заключение.

1. Медицинский работник выбирает решение «Запрещено».
2. Система отображает поле для указания причины запрета на выход учащегося.
3. Медицинский работник указывает причину отказа.
4. Медицинский работник подтверждает отрицательное медицинское заключение.
5. Система сохраняет отрицательное медицинское заключение вместе с указанной причиной.
6. Система присваивает заявке статус «Отклонено».
7. Система направляет родителю уведомление об отказе с указанием причины.

### 6а.3а. Причина отказа не указана.

1. Система обнаруживает, что поле для указания причины отказа не заполнено.
2. Система отображает сообщение о необходимости указать причину отказа.
3. Медицинский работник заполняет поле с причиной отказа.
4. Сценарий продолжается с шага 3 расширения 6а.

### 2а, 4а, 7а, 8а, 10а, 6а.5а, 6а.6а. Возникают технические неполадки при выполнении операций.

1. Система обнаруживает техническую ошибку при выполнении операции.
2. Система сообщает медицинскому работнику о возникновении технических неполадок.
3. Система предлагает повторить попытку позднее.
4. Выполнение сценария завершается.
