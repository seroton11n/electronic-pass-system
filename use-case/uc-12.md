# UC-12. Просмотр заявок

## 1. Контекст использования

Воспитатель использует раздел «Заявки», чтобы просматривать заявки на выход учащихся своего класса, отслеживать ход их согласования, знакомиться с заявками, ожидающими его рассмотрения, и просматривать результаты ранее принятых решений.

## 2. Область действия

Веб-приложение «Электронный пропуск».

## 3. Основное действующее лицо

Воспитатель.

## 4. Участники

Отсутствуют.

## 5. Предусловия

1. Воспитатель авторизован в системе.
2. За воспитателем закреплён класс учащихся.

## 6. Гарантии успеха

1. Воспитателю доступны списки заявок учащихся закреплённого за ним класса, сгруппированные по вкладкам «На согласовании», «Ожидают рассмотрения» и «Рассмотренные заявки».
2. Воспитатель может просматривать подробную информацию по выбранной заявке и отслеживать текущий этап её согласования.
3. Воспитатель может просматривать результаты ранее принятых решений по заявке, по которой было принято окончательное решение, включая информацию о том, кем и на каком этапе было принято окончательное решение.
4. Воспитатель может экспортировать данные о рассотренных заявках в формате PDF или Excel.

## 7. Триггер

Воспитателю необходимо просматривать заявки на выход учащихся своего класса, отслеживать ход их согласования и знакомиться с результатами принятых решений.

## 8. Основной сценарий

1. Воспитатель открывает раздел «Заявки».
2. Система отображает страницу «Заявки» и по умолчанию открывает вкладку «Ожидают рассмотрения».
3. Система отображает список заявок, ожидающих рассмотрения воспитателем. Для каждой заявки указываются:
   - фамилия и имя учащегося;
   - дата и время выхода;
   - причина выхода;
   - сведения о сопровождающем лице.
4. Система отображает вкладки «На согласовании», «Ожидают рассмотрения» и «Рассмотренные заявки».
5. При необходимости воспитатель выбирает вкладку «На согласовании».
6. Система отображает список заявок, которые находятся на этапах медицинской проверки или согласования заместителем директора. Для каждой заявки отображаются сведения об учащемся, дата и время выхода, а также текущий этап согласования.
7. При необходимости воспитатель выбирает вкладку «Рассмотренные заявки».
8. Система отображает список заявок, по которым принято окончательное решение. Для каждой заявки указываются:
   - фамилия и имя учащегося;
   - дата и время выхода;
   - итоговый статус заявки: «Одобрено» или «Отклонено».
9. Воспитатель выбирает заявку из одного из списков, чтобы ознакомиться с подробной информацией.
10. Система открывает подробную карточку выбранной заявки и отображает:
    - сведения об учащемся: фамилию, имя и класс;
    - дату и время выхода;
    - дату и время возвращения;
    - причину выхода;
    - сведения о сопровождающем лице;
    - текущий статус заявки.
11. В зависимости от состояния выбранной заявки система отображает информацию о ходе согласования:
    - для заявок, находящихся на согласовании, — текущий этап и результаты уже пройденных этапов;
    - для рассмотренных заявок — информацию о том, кем и на каком этапе было принято окончательное решение. При отклонении заявки система отображает причину отказа, если она была указана. В случае отклонения медицинским работником система отображает только факт отказа на данном этапе без медицинских комментариев и подробностей.
12. Воспитатель возвращается к списку заявок.

## 9. Альтернативный сценарий (расширение)

### 3а, 6а, 8а. В выбранной вкладке отсутствуют заявки.

1. Система отображает пустой список заявок.
2. Система сообщает об отсутствии заявок в выбранной вкладке.
3. Выполнение сценария продолжается.

### 7а. Воспитателю необходимо экспортировать рассмотренные заявки.

1. Воспитатель выбирает действие экспорта во вкладке «Рассмотренные заявки».
2. Система предлагает выбрать формат экспорта: PDF или Excel.
3. Воспитатель выбирает нужный формат.
4. Система формирует файл с данными о рассмотренных заявках в выбранном формате и предоставляет его для сохранения.
5. Выполнение сценария завершается.

### 2а, 3б, 6б, 8б, 10а. Возникают технические неполадки при загрузке данных.

1. Система обнаруживает техническую ошибку при выполнении операции.
2. Система сообщает воспитателю о возникновении технических неполадок.
3. Система предлагает повторить попытку позднее.
4. Выполнение сценария завершается.

### 7б. Возникает ошибка при формировании файла экспорта.

1. Система обнаруживает ошибку при формировании файла.
2. Система сообщает воспитателю о невозможности выполнить экспорт.
3. Система предлагает повторить попытку позднее.
4. Выполнение сценария завершается.
