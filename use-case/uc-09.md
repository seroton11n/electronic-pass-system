# UC-09. Рассмотрение заявки

## 1. Контекст использования

Заместитель директора по воспитательной работе рассматривает заявки на выход учащихся, чтобы оценить обоснованность указанной причины выхода с учётом обстоятельств и принять решение о согласовании или отклонении заявки.

## 2. Область действия

Веб-приложение «Электронный пропуск».

## 3. Основное действующее лицо

Заместитель директора по воспитательной работе.

## 4. Участники

Отсутствуют.

## 5. Предусловия

1. Заместитель директора по воспитательной работе авторизован в системе.
2. Заявка прошла медицинскую проверку с положительным заключением и ожидает рассмотрения заместителем директора по воспитательной работе.

## 6. Гарантии успеха

1. Решение заместителя директора по воспитательной работе сохранено в системе.
2. При согласовании заявке присвоен статус «Согласовано», и она передана воспитателю для дальнейшего согласования.
3. При отклонении заявке присвоен статус «Отклонено», сохранена причина отклонения, а родителю отправлено уведомление с указанием этой причины.

## 7. Триггер

Заместителю директора по воспитательной работе необходимо рассмотреть поступившую заявку и принять по ней решение.

## 8. Основной сценарий

1. Заместитель директора по воспитательной работе открывает раздел «Заявки».
2. Система отображает страницу «Заявки» с указанием даты, на которую сформирован список заявок.
3. Система отображает список классов. Для каждого класса указываются:
   - наименование класса;
   - фамилия и инициалы воспитателя;
   - количество заявок, ожидающих рассмотрения;
   - количество уже согласованных заявок.
4. Заместитель директора по воспитательной работе выбирает нужный класс.
5. Система отображает список заявок учащихся выбранного класса за указанную дату. Для каждой заявки отображаются:
   - фамилия и имя учащегося;
   - причина выхода;
   - сведения о сопровождающем лице;
   - кнопки «Одобрить» и «Отклонить» для заявок, ожидающих рассмотрения.
6. Заместитель директора по воспитательной работе выбирает заявку, которую необходимо рассмотреть.
7. Система открывает подробную карточку выбранной заявки и отображает:
   - сведения об учащемся: фамилию, имя и класс;
   - дату и время выхода;
   - дату и время возвращения;
   - причину выхода;
   - сведения о сопровождающем лице;
   - результат медицинской проверки;
   - комментарий медицинского работника, если он был оставлен;
   - текущий статус заявки.
8. Заместитель директора по воспитательной работе изучает информацию и оценивает обоснованность указанной причины выхода.
9. Заместитель директора по воспитательной работе выбирает действие «Одобрить».
10. Система сохраняет принятое решение и изменяет статус заявки на «Согласовано».
11. Система передаёт заявку воспитателю для дальнейшего согласования.

## 9. Альтернативные сценарии (расширения)

### 3а. В системе отсутствуют заявки за выбранную дату.

1. Система сообщает об отсутствии заявок за выбранную дату.
2. Выполнение сценария завершается.

### 5а. В выбранном классе отсутствуют заявки, ожидающие рассмотрения.

1. Система сообщает об отсутствии заявок, требующих рассмотрения.
2. Заместитель директора по воспитательной работе может просмотреть уже согласованные заявки.
3. Выполнение сценария завершается.

### 9а. Заместитель директора по воспитательной работе отклоняет заявку.

1. Заместитель директора по воспитательной работе выбирает действие «Отклонить».
2. Система отображает поле для ввода причины отклонения.
3. Заместитель директора по воспитательной работе указывает причину отклонения.
4. Заместитель директора по воспитательной работе подтверждает отклонение заявки.
5. Система сохраняет принятое решение и указанную причину.
6. Система изменяет статус заявки на «Отклонено».
7. Система отправляет родителю уведомление с указанием причины отклонения.
8. Сценарий завершается.

### 9а.1. Причина отклонения не указана.

1. Система отображает сообщение о необходимости указать причину отклонения.
2. Заместитель директора по воспитательной работе вводит причину.
3. Выполняется переход к шагу 4 сценария 9а.

### 2а, 3б, 5б, 7а, 10а, 11а, 9а.5а–9а.7а. Возникают технические неполадки при загрузке или сохранении данных.

1. Система обнаруживает техническую ошибку при выполнении операции.
2. Система сообщает заместителю директора по воспитательной работе о возникновении технических неполадок.
3. Система предлагает повторить попытку позднее.
4. Выполнение сценария завершается.
