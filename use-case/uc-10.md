# UC-10. Просмотр текущих выходов учащихся

## 1. Контекст использования

Заместитель директора по воспитательной работе имеет возможность просматривать сведения об учащихся, которые в данный момент находятся за территорией гимназии-интерната, чтобы отслеживать текущие выходы и контролировать своевременное возвращение учащихся.

## 2. Область действия

Веб-приложение «Электронный пропуск».

## 3. Основное действующее лицо

Заместитель директора по воспитательной работе.

## 4. Участники

Отсутствуют.

## 5. Предусловия

1. Заместитель директора по воспитательной работе авторизован в системе.
2. В системе зафиксирован фактический выход учащегося за территорию гимназии-интерната, при этом фактическое возвращение учащегося ещё не зафиксировано.

## 6. Гарантии успеха

1. Заместителю директора по воспитательной работе доступен список учащихся, которые в текущий момент находятся за территорией гимназии-интерната.
2. Заместитель директора по воспитательной работе может просмотреть подробную информацию о выбранном учащемся.
3. Заместителю директора по воспитательной работе доступна возможность экспорта данных о текущих выходах учащихся в форматах PDF и Excel.

## 7. Триггер

Заместителю директора по воспитательной работе необходимо ознакомиться с актуальной информацией об учащихся, которые в данный момент находятся за территорией гимназии-интерната, или сохранить эти данные для дальнейшего использования


## 8. Основной сценарий

1. Заместитель директора по воспитательной работе открывает раздел «Текущие выходы учащихся».
2. Система отображает список учащихся, которые в данный момент находятся за территорией гимназии-интерната. Для каждого учащегося указываются:
   - фамилия и имя;
   - класс;
   - фактическое время выхода;
   - планируемое время возвращения.
3. Заместитель директора по воспитательной работе выбирает учащегося, подробную информацию о котором хочет просмотреть.
4. Система раскрывает карточку выбранного учащегося и отображает:
   - фамилию, имя и класс учащегося;
   - дату выхода;
   - причину выхода;
   - сведения о сопровождающем лице;
   - фактическое время выхода;
   - cотрудник охраны, зафиксировавший выход;
   - планируемое время возвращения.
5. Заместитель директора по воспитательной работе изучает информацию о выбранном учащемся.

## 9. Альтернативные сценарии (расширения)

**2а. В системе отсутствуют текущие выходы.**

1. Система сообщает об отсутствии учащихся, находящихся за территорией гимназии-интерната.
2. Выполнение сценария завершается.
   
**2в. Заместитель директора по воспитательной работе принимает решение экспортировать данные.**
1. Заместитель директора по воспитательной работе нажимает кнопку «Экспортировать», расположенную в верхней части страницы.
2. Система предлагает выбрать формат файла: PDF или Excel.
3. Заместитель директора по воспитательной работе выбирает необходимый формат.
4. Система формирует файл с данными о текущих выходах учащихся в выбранном формате.
5. Система предоставляет возможность сохранить сформированный файл на устройство пользователя.
6. Сценарий продолжается с шага 3 основного сценария.

**2б. При загрузке данных или формировании файла экспорта возникает техническая ошибка.**

1. Система обнаруживает техническую ошибку при выполнении операции.
2. Система отображает сообщение о возникшей технической ошибке.
3. Выполнение сценария завершается.
